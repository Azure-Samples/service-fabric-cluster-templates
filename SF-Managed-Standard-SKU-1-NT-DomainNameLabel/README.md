# Standard SKU Service Fabric managed cluster, 1 node type

[![Deploy to Azure](https://aka.ms/deploytoazurebutton)](https://portal.azure.com/#create/Microsoft.Template/uri/https%3A%2F%2Fraw.githubusercontent.com%2FAzure-Samples%2Fservice-fabric-cluster-templates%2Fmaster%2FSF-Managed-Standard-SKU-1-NT-DomainNameLabel%2FAzureDeploy.json)
[![Visualize](http://armviz.io/visualizebutton.png)](http://armviz.io/#/?load=https%3A%2F%2Fraw.githubusercontent.com%2FAzure-Samples%2Fservice-fabric-cluster-templates%2Fmaster%2FSF-Managed-Standard-SKU-1-NT-DomainNameLabel%2FAzureDeploy.json)

This template allows you to deploy a Service Fabric managed cluster using the *Standard* SKU. This cluster contains a single node type running *Windows Server 2022 Datacenter* on a *Standard_D2s_v3* SKU size on Azure Virtual Machine Scale Set. The cluster is configured with a domain name label for the public endpoint which provides a static connection to cluster with cluster certificate common name. This configuration is suitable for connectivity to the cluster requiring use of cluster certificate. The new FQDN format for the cluster is: **`<cluster-name>.<random generated string>.<region>.sfmc.io`**.

```json
"autoGeneratedDomainNameLabelScope": "ResourceGroupReuse",
```

By default, to connect to a managed cluster, the cluster certificate thumbprint has to be used and is rotated every 90 days. This requires updating connection configuration for downlevel services. This template allows you to deploy a cluster with a static domain name label configuration for the public endpoint which can be used to connect to the cluster using the cluster certificate common name.

## Template Configuration

- Cluster SKU: Standard
- autoGeneratedDomainNameLabelScope: ResourceGroupReuse
- Automatic OS Upgrade configuration
- Remote Desktop: Disabled

## Use Powershell to deploy your cluster

Go through the process of creating the cluster as described in [Deploy a Service Fabric managed cluster](https://docs.microsoft.com/azure/service-fabric/tutorial-managed-cluster-deploy)

## Use Powershell to connect to your cluster

Execute from a windows powershell command prompt with the Service Fabric SDK and Azure Az.Resources installed. The Service Fabric SDK can be installed from the [Download and install the runtime and SDK](https://learn.microsoft.com/azure/service-fabric/service-fabric-get-started) page.

```powershell
import-module servicefabric
import-module az.resources

$location = '<location>'
$clusterName = '<cluster name>'
$clusterResource = Get-AzResource -ResourceGroupName $resourceGroupName `
  -Name $clusterName `
  -ResourceType 'Microsoft.ServiceFabric/managedclusters' `
  -ExpandProperties
$serverCertThumbprint = $clusterResource.Properties.clusterCertificateThumbprints
$clusterFqdn = $clusterResource.Properties.fqdn
$clusterEndpoint = "$($clusterFqdn):19000"

# if using client thumbprint
Connect-ServiceFabricCluster -ConnectionEndpoint $clusterEndpoint `
        -ServerCommonName $clusterFqdn `
        -StoreLocation CurrentUser `
        -StoreName My `
        -X509Credential `
        -FindType FindByThumbprint `
        -FindValue '<client certificate thumbprint>' `
        -Verbose

# or if using client common name
Connect-ServiceFabricCluster -ConnectionEndpoint $clusterEndpoint `
    -ServerCommonName $clusterFqdn `
    -StoreLocation CurrentUser `
    -StoreName My `
    -X509Credential `
    -FindType FindBySubjectName `
    -FindValue '<client certificate subject name>' `
    -Verbose
```
